# 🏦 Banking Analytics Dashboard

## 📌 Project Overview

This project is an interactive **Power BI Banking Analytics Dashboard** built to analyze banking data using visualizations and KPIs.

## 📊 Features

* Total Revenue
* Total Expenses
* Total Profit
* Customer Distribution by Customer Type
* Revenue by City
* Monthly Transaction Trend
* Region Filter (Slicer)

## 🛠️ Tools Used

* Microsoft Power BI Desktop
* Power Query
* CSV Dataset

## 📂 Dataset

The dashboard uses the following datasets:

* `bank_data.csv`
* `customer_data.csv`
* `transaction_data.csv`

## 📈 Dashboard

The dashboard includes:

* KPI Cards
* Pie Chart
* Bar Chart
* Line Chart
* Region Slicer
